# Spatial-operator experiment entry point (Fig. 6–7)

The release archive already contains `com.SpatialOperatorPipeline` and its
complete spatial candidate/coverage operators. It does not expose a
standalone main method. `configs/tools/ArtifactSpatialOperatorMain.java`
adds that entry without changing the production ZIP. The helper:

- reads the same prepared XY input in Spark, assigns stable point IDs;
- calls `SpatialOperatorPipeline.evaluate` from the released source JAR;
- exports members for each returned circle and cross-checks member counts;
- reports the current whole-query time including loading and export.

From the repository root (after extraction/build of `DiSMC-source`):

```bash
export SPARK_MASTER=spark://your-master:7077
export SPARK_HOME=/path/to/spark-3.2.0
TRIALS=3 bash configs/run_paper_suite.sh fig6
TRIALS=3 bash configs/run_paper_suite.sh fig7
```

The adapter compiles against JDK 8 and Spark 3.2.0 on first use.
The original historical sorted-coverage streaming binary is not in
the source ZIP; do not imply its timing was generated by this adapter.
Data sizes, query coordinates, radii and repeats follow the supplement.
