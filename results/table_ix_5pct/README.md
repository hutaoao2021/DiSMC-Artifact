# Optional verification note: supplementary Table IX

Table IX is a **supporting budget-feasibility diagnostic**, not a separate principal contribution or mandatory artifact for the DiSMC release.

Its two rows of reported numbers are included in [`../table_ix_5pct.csv`](../table_ix_5pct.csv), while the definitions, experiment conditions, and interpretation are in the **18-page supplementary PDF**.

For manuscript checking, the authors separately supplied raw selected-plan and per-owner charge records, and checked the reported fees. Those records were provided to verify the paper; **a standalone Table IX evidence ZIP is not required as a core release deliverable**, and the public release checklist does not depend on one.

**Metric boundary:** the Dependency execution was run once per dataset; the Full-parent alternative was **cost-accounted only**, not timed. This diagnostic is distinct from the three-run Full-parent/Dependency online E2E experiment in main-paper Fig. 10.

The general experimental data, source entry points and result summaries are documented in [`../README.md`](../README.md) and [`../../configs/experiment-settings.md`](../../configs/experiment-settings.md).
